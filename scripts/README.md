# Scripts

Optional but recommended: add a PowerShell script here that reproduces part
of the build (e.g. bulk-creating the six users and groups via
`New-ADUser` / `New-ADGroup`, or an audit script that lists group
memberships and NTFS permissions). Even a small script here goes a long
way — it's concrete, checkable proof of hands-on work rather than just
screenshots of GUI clicks.
